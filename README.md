# כיס — מעקב הוצאות לאייפון (PWA)

## העלאה ל-GitHub Pages (פעם אחת, כ-5 דקות)
1. ב-github.com: New repository, שם לדוגמה `kesef`, Public.
2. Add file → Upload files → גרור את **כל** הקבצים והתיקייה `icons` → Commit.
3. Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `root` → Save.
4. אחרי דקה הכתובת תופיע שם: `https://<user>.github.io/kesef/`

## התקנה באייפון
1. פותחים את הכתובת ב-**Safari** (לא בכרום).
2. כפתור שיתוף → "הוסף למסך הבית".
3. מעכשיו פותחים מהאייקון. האפליקציה עובדת גם בלי אינטרנט.

## חשוב לדעת
- הנתונים נשמרים רק באייפון (אף שרת לא רואה אותם). מחיקת האפליקציה ממסך הבית מוחקת אותם.
- גיבוי: הגדרות → שמירת גיבוי (קובץ JSON לקבצים/iCloud). כדאי פעם בחודש.
- עדכון גרסה: מעלים קבצים חדשים ומשנים את `VERSION` בקובץ `sw.js`.

## קבצים
- `index.html` — כל האפליקציה (מסכים, לוגיקה, עיצוב)
- `sw.js` — עבודה בלי אינטרנט
- `manifest.webmanifest`, `icons/` — התקנה למסך הבית
- `xlsx.full.min.js` — ספריית SheetJS לייצוא Excel (מקומית, בלי CDN)
